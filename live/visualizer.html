Payments

Each bay is a real OCPP 1.6J charge point running in this page: it boots, authorizes the resident's RFID tag against their server-side wallet, starts a transaction, streams meter values stamped with the simulation clock, and stops — the Python CSMS prices every interval by the tariff band in force at its timestamp and debits the wallet. Traffic mode simply drives the same bays automatically. A real charger pointed at this server would be billed identically.
